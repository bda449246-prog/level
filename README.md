# 水準器

iPhoneの「計測」アプリの水準器をWebで再現し、傾きを0.1°単位で表示します。

公開ページ: https://bda449246-prog.github.io/level/

縦に持ってタップすると、本当の地面(白)に加えて、タップした姿勢を基準にした地面(赤)が現れ、2枚が交差しながら回転します。基準からの角度は±180°まで表示し、数字は現実の水平に合わせて回転します。

以前の版(基準設定で画面全体が赤くなる版)は https://bda449246-prog.github.io/level/classic/ に残しています。

iPhoneのSafariで開き、画面をタップしてモーションへのアクセスを許可すると使えます。

## 水準器ピアノ

https://bda449246-prog.github.io/level/piano/

水準器の傾き角度をピアノの音階に対応させ、傾けると角度に合わせた音が鳴ります。楽器はピアノ・アコースティックギター・バイオリン・トランペット・サックスから選べます。バイオリン・トランペット・サックスは傾けている間ずっと音が伸び、傾きを変えると音がつながって動きます。0°が「ド(C4)」で、設定した角度ごとに1音ずつ上下します。

演奏のしかたは「単音」「和音」「アルペジオ」から選べます。和音・アルペジオでは、傾きで和音が切り替わります(ドレミ: C → Dm → Em → F → G → Am → Bdim、半音: 半音ずつのメジャーコード)。

## そそぐ水準器

https://bda449246-prog.github.io/level/pour/

端末を立てて持ち、傾けて水を注ぐ液体パズルです。容器は画面に固定され、中の水は現実の重力どおり水平を保ちます。緑の線の範囲まで入れて1.2秒キープするとクリアで、こぼした水が少ないほど星が増えます(全6ステージ)。

## ガラスの水準器

https://bda449246-prog.github.io/level/glass/

ガラス玉風デザインの水準器です。緑の玉が中心に合うと背景いっぱいに波紋が広がり、タップで今の角度を基準にできます(0.1°表示)。上部のボタンで黒・赤・緑の3テーマを切り替えられ、`#black` `#red` `#green` を付けたURLで最初のテーマを指定できます。

## 水準器ドライブ

https://bda449246-prog.github.io/level/drive/

水準器の傾きをハンドルに見立てて、町の中で車を運転するゲームです。スマホを両手で持ってハンドルのように左右に回すと曲がり、右下のアクセル・左下のブレーキで走ったり止まったりします(止まった状態でブレーキを押し続けるとバック)。傾きは0.1°単位で表示され、「0°合わせ」で今の持ち方をまっすぐにできます。左側通行の町で、緑の目的地5か所に荷物を届けるまでのタイムを競います。センサーがない環境では、ドラッグや矢印キーで操作できます。

## 水準器ファイト

https://bda449246-prog.github.io/level/fight/

水準器の傾きで自分の体の倒れ具合を変えて戦う格闘ゲームです。スマホを立てて持ち、右へ傾けると前(相手のほう)へ、左へ傾けると後ろへ、その角度だけ体が倒れます。相手の攻撃は予告が出るので、上段パンチは大きく倒して、中段キックは後ろへ、かかと落としは前へ倒してよけます。前へ35°以上すばやく倒すとパンチになり、よけた直後や相手が構えている最中に当てると大ダメージです。3人の相手(後半はフェイントあり)に勝ち抜きます。

## 立体水準器

https://bda449246-prog.github.io/level/3d/

スマホの中にガラスの球があり、中の白い水面がいつも本物の地面と平行に保たれる3次元の水準器です。平置き・縦に立てる・横に立てるのどれでも0.1°単位で角度を表示し、水平になると画面が緑に変わります。タップするとその時の傾きを赤い基準面として記録し、基準からの角度を測れます。視点は「正面・斜め・横」の切り替えやドラッグで回せます。

- ジャイロ併用: 回転センサーと加速度センサーを組み合わせ、動かしている最中も水面が素早く安定して追従します(ジャイロの向きは自動で確認してから使います)。
- 単位切り替え: 角度(°)・勾配(%)・1mあたりの高さ(mm/m)を切り替えられます。
- 目標角度: 「目標」から角度を入れると、その角度になったときに緑になり、あと何度かを表示します。
- オフライン対応: 一度開けば電波がなくても使えます。ホーム画面に追加するとアプリのように起動します。
- 数字の向き: 立てたときは数字が水平線と一緒に回り、平置きでは持ち方に合わせて向きが変わります。

## 水素原子の立体水準器

https://bda449246-prog.github.io/level/atom/

立体水準器のガラス球の中に水素原子の模型を入れたページです。電子雲モードでは、1s〜4fまでの軌道を、波動関数の2乗(電子がいそうな確率)にしたがって点の雲で描き、符号を色で分けます。ボーア模型モードでは、半径 n²×0.0529 nm の円軌道を電子が回ります。軌道の向きを決める軸は水準器の水面と同じく本物の鉛直方向に保たれ、上部には水準器と同じ角度が表示されます。「光を吸収/放出」で電子が別の軌道に移り、その波長(ライマン・バルマー・パッシェン系列)の光が出入りします。
