# 水準器

iPhoneの「計測」アプリの水準器をWebで再現し、傾きを0.1°単位で表示します。

公開ページ: https://bda449246-prog.github.io/level/

縦に持ってタップすると、本当の地面(白)に加えて、タップした姿勢を基準にした地面(赤)が現れ、2枚が交差しながら回転します。基準からの角度は±180°まで表示し、数字は現実の水平に合わせて回転します。

以前の版(基準設定で画面全体が赤くなる版)は https://bda449246-prog.github.io/level/classic/ に残しています。

iPhoneのSafariで開き、画面をタップしてモーションへのアクセスを許可すると使えます。

## 水準器ピアノ

https://bda449246-prog.github.io/level/piano/

水準器の傾き角度をピアノの音階に対応させ、傾けると角度に合わせた音が鳴ります。楽器はピアノ・アコースティックギター・バイオリン・トランペット・サックスから選べます。バイオリン・トランペット・サックスは傾けている間ずっと音が伸び、傾きを変えると音がつながって動きます。0°が「ド(C4)」で、設定した角度ごとに1音ずつ上下します。

演奏のしかたは「単音」「和音」「アルペジオ」から選べます。和音・アルペジオでは、傾きで和音が切り替わります(ドレミ: C → Dm → Em → F → G → Am → Bdim、半音: 半音ずつのメジャーコード)。

## そそぐ水準器

https://bda449246-prog.github.io/level/pour/

端末を立てて持ち、傾けて水を注ぐ液体パズルです。容器は画面に固定され、中の水は現実の重力どおり水平を保ちます。緑の線の範囲まで入れて1.2秒キープするとクリアで、こぼした水が少ないほど星が増えます(全6ステージ)。

## ガラスの水準器

https://bda449246-prog.github.io/level/glass/

ガラス玉風デザインの水準器です。緑の玉が中心に合うと背景いっぱいに波紋が広がり、タップで今の角度を基準にできます(0.1°表示)。上部のボタンで黒・赤・緑の3テーマを切り替えられ、`#black` `#red` `#green` を付けたURLで最初のテーマを指定できます。
